# Memory and Knowledge

Knowledge survives through people, material traces, and deliberate preservation. A memory can remain true to a past moment even when the world it describes has changed.

## Grimnir Memory Stones

Memory stones carry impressions, stories, and practical knowledge through resonance and attunement. Archival stones preserve chosen knowledge over generations, allowing a discovery to outlive its discoverer. Memory-Keepers help others interpret ancestral experiences, emotions, and craft held in these patterns. Later Skykeepers carry records between communities.

## Echo Cradles

An Echo Cradle is a shaped, reusable base into which a memory or archival stone is seated. It provides the physical setting for binding known experiences into the stone or absorbing the knowledge it holds. Learning from a stone need not empty it; others may learn from it in turn.

## The Memory Fountain

The Memory Fountain is a communal place of knowledge exchange. People bring discoveries and seek the experience of others. Memory Binding joins a stone to the Fountain: the physical stone is consumed while its memories enter the communal store. Archival stones and the Fountain serve different forms of preservation; their exact relationship over long periods remains open.
